Xtrabackup Binary Install

// Download URL
https://www.percona.com/downloads/

glibc 버전 및 mysql 버전에 맞게끔 다운로드
OS Version			- Rocky Linux 9.8
DB version 			- mysql 8.4.8
Xtrabackup version 	- 8.4.0-6

$ tar -xvf percona-xtrabackup-8.4.0-6-Linux-x86_64.glibc2.34.tar
$ mv percona-xtrabackup-8.4.0-6-Linux-x86_64.glibc2.34 xtrabackup
$ sudo mv xtrabackup /usr/local/


//환경변수 셋팅

$ vi .bash_profile

====================================

export MYSQL_HOME=/usr/local/mysql
export XTRABACKUP_HOME=/usr/local/xtrabackup
export PATH=$XTRABACKUP_HOME/bin:$MYSQL_HOME/bin:$PATH

====================================

// 실행 확인
$ xtrabackup --version
xtrabackup version 8.4.0-6 based on MySQL server 8.4.0 Linux (x86_64) (revision id: 46a895ed)
